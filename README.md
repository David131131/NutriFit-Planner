# 🥗 NutriFit-Planner

个性化减脂饮食方案生成工具 / Personalized Fat-Loss Meal Plan Generator

一个**纯静态网页应用**：输入身高、体重、目标体重、年龄、生理性别、所在地区与运动量，即可自动估算体脂率与每日热量消耗，生成 **6 套差异化饮食方案**（高性价比 / 均衡 / 最快速 / 学生友好 / 高蛋白低碳 / 本地传统），对比成本与达成天数，并生成**一周早午晚三餐日程（一周菜品不重复）**。界面支持中英双语与 CNY/USD/EUR 显示。

## ✨ 功能

1. **基础数据录入**：身高、体重、目标体重、年龄、生理性别、地区（9 大地区）、日常活动水平、每日额外运动消耗（可选大概范围）、学生身份、目标偏好。
   - 目标体重健康检查：目标 BMI < 18.5 会提示偏瘦；< 17 / < 16 会触发**红色警告并要求确认**；未成年人、当前已偏瘦、减重幅度过大等均有相应提醒。
   - **双模式**：目标体重低于当前体重 = 减脂模式（热量缺口）；高于当前体重 = **增肌模式（热量盈余 +300~+500 千卡、蛋白质上调至 1.8–2.4 g/kg）**，其余流程一致。目标 BMI ≥ 28 / 增重超过 15 公斤同样会警告。
2. **计算模块**：
   - 体脂率估算（Deurenberg 公式，显示 ±4% 区间与分级）
   - 基础代谢 BMR（Mifflin-St Jeor）
   - 每日总消耗 = BMR × 活动系数 + 额外运动消耗
   - 建议每日摄入范围、减脂总热量缺口、三大营养素建议范围
3. **内置数据库**：
   - 食材库 161 种（名称 / 参考热量 / 参考单价 / 地区分类 / 分类浏览）
   - 各地区菜谱 228 道（东亚 30 · 东南亚 24 · 南亚 24 · 中东 18 · 欧洲 24 · 北美 24 · 拉美 18 · 非洲 18 · 大洋洲 24 · 通用池 24），每道菜含食材克数、热量、成本与一句话做法
4. **6 套饮食方案**，各自有不同目标天数、每日热量、成本与速度：
   - 💰 高性价比方案（最省钱）
   - ⚖️ 均衡方案（最易坚持）
   - ⚡ 最快速方案（缺口最大；当安全下限限制进度时会要求每日额外运动）
   - 🎒 学生友好方案（全部免煮/微波/即食：袋装即食鸡胸肉、即食牛肉、即食燕麦、罐头、面包、牛奶）
   - 🥩 高蛋白低碳方案
   - 🍲 本地传统方案（贴合地区饮食习惯）
5. **方案对比表**：每日热量 / 每日成本 / 预计天数 / 预计总成本 / 周减重 / 难度。
6. **一周日程生成**：周一至周日 × 早/午/晚/加餐，**一周 21 道料理不重复**（食材可重复）；自动按目标热量进行份量缩放；点击菜品查看食材明细与分步做法；支持「换一批菜品」重新生成与**导出 Excel 表格**（行=早/午/晚/加餐，列=周一至周日，带样式）。
7. **免责声明**：算法结果仅供参考、不具医疗效力；基础疾病人群请咨询医师；地区适配有限等。

## 🛠 算法参考

- BMI = 体重 ÷ 身高²（分级：中文界面采用中国标准，英文界面采用 WHO 标准）
- 体脂率：Deurenberg 公式 `BF% = 1.20×BMI + 0.23×年龄 − 10.8×性别 − 5.4`（约 ±4%）
- BMR：Mifflin-St Jeor 公式
- 每日总消耗 = BMR × 活动系数 + 额外运动消耗
- 1 公斤脂肪 ≈ 7700 千卡；预计天数 = 需减重量 ÷ 周减重速度（附 ±20% 浮动区间）
- 安全下限：女性 ≥ 1200 千卡/天，男性 ≥ 1500 千卡/天，且不低于 BMR
